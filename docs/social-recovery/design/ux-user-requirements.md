# UX user requirements
This file holds one row per requirement of the recovery experience, written for the partner's engineer and for a reviewer who never sat in the design conversation. Each row names at least one persona from `design/personas/`, the story it belongs to in `ux-user-stories.md` and, where one exists, the interface it lands on in `ux-interfaces.md`.

Priority is must, should or could for the release the row names in its release column, first, second or third. D-313 argues the split. Ids mint from the ux chapter's D-300 band. The flow each row belongs to is the section of `ux.md` that argues it. The rows are grouped by the vertical of `ux.md` that argues them, in the plan's order.
